# MyProject_OpenAPIMockServer

## OpenAPI Mock Server Generator

**Problem Statement #41 -- Developer Tools & IT Operations**

This repository contains the individual project work for the **OpenAPI
Mock Server Generator**.

The project is a developer productivity tool that takes an OpenAPI 3.0
YAML/JSON specification and is intended to generate dynamic mock REST
endpoints with schema validation and configurable response latency.

### Project Actors

-   API Developer
-   QA Engineer

## Main Requirements

The main functional requirements are related to:

1.  Generating dynamic mock endpoints from OpenAPI 3.0 schemas.
2.  Providing OpenAPI YAML/JSON specification input.
3.  Validating API requests and responses against the defined schemas.
4.  Configuring simulated response latency.
5.  Providing generated endpoint details for API testing.

The non-functional requirements include performance/latency expectations
and safe handling of malformed or unsupported OpenAPI specifications.
